## 2026-10-08 — v0.5 훅·메시지·모션 (사용자: "자동화 결과물이 만족스럽지 않다. 훅킹 포인트, 강력한 메시지 전달, 모션 그래픽까지 자동화")

- 원인 진단: 플래너가 훅을 "가장 강한 문장 하나"로만 고르고 메시지 설계 단계가 없었음. 빌더에는 움직임·카드 장치가 없어 자막만 바뀌는 정적인 결과물
- **플래너:** 작업 순서를 key_message → 훅 후보 3개(질문/숫자/반전/고백/경고) 비교·선택(콜드 오픈) → 컷 선택으로 고정. 첫 컷 4초 이내·인사 금지, 강조의 경제(emphasis 3~5, alert 0~2), 문장형 라벨, `hook`·`message_cards` 출력
- **`critique`:** 계획 강도 점검(훅 패턴 감지, 첫 컷 길이, key_message·카드·엔딩 일치, 강조·라벨 수, 템포, 16자 넘는 자막). `agent.py critique`, import-plan 뒤 자동 표시, /edit 자기 점검 단계
- **API 리뷰 패스:** 계획 생성 후 critique 결과를 붙여 편집장 프롬프트로 한 번 더 강화(`--no-review`로 생략). 검증 실패 시 원래 계획 유지
- **빌더:** 훅 카드(상단 그라데이션 + 큰 글씨 + 보조 문구), 메시지 카드(띠 배경 + 문장/숫자형, `replace_subs`), 효과음 자동 배치(SFX/ 폴더), 단어 타임스탬프를 자막에 부착
- **`motion.py`:** 캡컷 키프레임(위치·배율·투명도) 생성 — 역할별 팝, 단어 단위 등장(reveal), 라벨 슬라이드, 카드·고지 페이드, 이미지 B롤 켄 번스, PIP 팝, 이름표 슬라이드. 스타일 `motion`으로 전부 조절, `enabled:false`로 끔
- `assets.py`: 띠(band)·상단 그라데이션 PNG. `make_template.py --inspect`: 캡컷이 저장한 키프레임/애니메이션 원문 출력(검증용)
- 스타일: target에 hook_card(위에서 11%/19%), message_card(얼굴을 가리지 않게 상단 8~28% 띠), talk_short는 title이 훅이라 hook_card 없음, message_card는 제목과 자막 사이(52~68%)
- 테스트 17개 통과(훅·카드·키프레임 포맷·reveal·효과음·critique·리뷰 패스). 합성 영상으로 미리보기 확인
- **검증 필요(사용자 PC):** 키프레임이 캡컷 9.4.0에서 열리고 재저장되는지. 안 되면 `motion.enabled:false` + `--inspect`로 실제 포맷 비교
