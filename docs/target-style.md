## 측정값 (720×1280 기준 → 캡컷 좌표)

캡컷 좌표: `transform.y` = (0.5 − 세로비율) × 2 (위가 +), `transform.x`는 반 화면 폭 단위.

| 요소 | 위치(픽셀) | 세로비율 | 캡컷 y |
|---|---|---|---|
| 본 자막 (한 줄) | 775–810 | 0.619 | **−0.238** |
| 맥락 라벨 박스 | 729–762 | 0.582 | **−0.164** |
| 상단 고지 라벨 | 약 60–80 | 0.055 | **+0.89** |
| 엔딩 메시지 박스 | 화면 중앙 약간 아래 | 약 0.53 | 약 **−0.06** |

색상:
- 본 자막 흰색 `#FEF9F6`, 노란색 **`#F2D475`** (실측 242,212,117), 얇은 어두운 외곽선/그림자
- 라벨: 검정 박스(불투명 ~85%) + 흰 글씨, 작은 크기
- 강조 빨강: `#E0324B` 계열 (예: "해킹하는 거예요..")

자막 글꼴: 둥근 손글씨 느낌의 한글 폰트(캡컷 폰트 중 선택 필요). 한 줄 8~14자.

## 편집 문법 (구성)

1. **훅(0~3초):** 가장 자극적인 한 문장 + 맥락 라벨 ("왜 이렇게 싸..?" + "50~70만 원이다..")
2. **경험담:** "실제 경험" 라벨, 화자 클로즈업
3. **재연:** 말로 설명하는 장면을 AI 일러스트로 전환하고 상단에 "AI로 생성한 이미지 입니다"를 넣음. 자막은 계속 유지
4. **정보:** 제품/장비 사진 PIP + 비교 라벨
5. **팁:** "또 하나 팁을 알려드리자면" → 노란 자막 강조
6. **엔딩 카드:** 핵심 메시지 한 문장, 검정 박스

## 남은 차이 / 다음 단계

- 자막 글꼴(둥근 손글씨체) — 캡컷 폰트 경로 지정 필요
- 텍스트 외곽선 검증 후 강조 자막에 적용
- 주석 텍스트 스타일(작은 노란 글씨)
- AI 재연 이미지 생성 연동 (지금은 `broll_ideas` 프롬프트만 출력 → 이미지 넣으면 `ai: true`로 배치)
- 음성 변조 고지 등 오디오 처리

## 구현 로드맵 (v0.3에서 1~6 완료)

1. 스타일 프리셋 `target`: 9:16 꽉 채움(가로 원본은 fill 확대, 얼굴 중심 x 보정), 자막 y −0.238, 영어 자막 끔
2. 자막 색 역할: 플랜의 `lines[].role` = `normal | quote | emphasis | aside(괄호 해설)` → 흰/노랑/크게/괄호
3. 라벨 트랙: `labels[]` (맥락 라벨, 상단 고지) — 검정 배경 텍스트 세그먼트
4. ~~펀치인 줌~~ — 구현했으나 사용자 요청으로 제외(2026-10-07)
5. 엔딩 카드: `ending: {text}` → 중앙 검정 박스 텍스트, 마지막 2~3초
6. 이미지 B롤: `broll[].src`가 이미지면 사진 세그먼트(+선택: 켄 번스), `label` 지원
